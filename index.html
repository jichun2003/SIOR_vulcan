Detection Model · YOLOv8

YOLOv8 is a one-stage object detector released by Ultralytics. It predicts box locations and classes in a single forward pass, which makes it fast enough for live video. It is anchor-free, predicting object centers directly, and uses a decoupled head that handles classification and box regression separately.

Custom trainingPhotographed the target, labeled it in Roboflow, and fine-tuned on a single class (target) at 640 px input
Real-time inferenceRuns on every webcam frame, keeps boxes above 0.4 confidence, and passes the chosen target's center to the controller
